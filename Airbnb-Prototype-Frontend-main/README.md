# The Lantern Stay Frontend

Next.js 16 + TypeScript + Tailwind CSS 4 booking experience for The Lantern Stay.

## Features

- Full-bleed branded landing page
- Stay search & filters
- Property detail with gallery, amenities, reviews
- Secure auth (JWT + cookies via API)
- Booking request flow
- Guest trips dashboard + host inbox
- Wishlist

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

App: [http://localhost:3000](http://localhost:3000)

Ensure the API is running on port 4000.
